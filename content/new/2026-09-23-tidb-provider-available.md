OpenEverest now supports [TiDB](https://github.com/pingcap/tidb), a distributed SQL database that handles both transactional and analytical workloads (HTAP). The new provider is built on TiDB Operator v2 and lets you provision, manage, and monitor TiDB clusters directly from the OpenEverest UI or API.

TiDB joins the growing list of OpenEverest-managed databases, giving teams a cloud-native option for distributed MySQL-compatible workloads with horizontal scalability.

The provider is available now. Install it via Helm or the OpenEverest Extension Hub.
