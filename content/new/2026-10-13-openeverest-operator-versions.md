OpenEverest 1.17.0 adds support for the two latest database operator releases: PostgreSQL operator v3.1.0 and Percona Server for MongoDB operator v1.23.1.

Both engines can now be deployed and managed at their newest operator versions directly from OpenEverest, so clusters pick up the upstream fixes and improvements without waiting for a platform update.

The new operator versions are available with OpenEverest 1.17.0. To learn more, visit the [release notes](https://github.com/openeverest/openeverest/releases/tag/v1.17.0).
